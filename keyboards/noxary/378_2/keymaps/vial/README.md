# 378v2 - VIAL keymap

VIAL-enabled keymap for the 378v2 keyboard.

## Details

- Processor family: ARM
- Lighting: qmk_backlight
- Encoders: 0
- Split: no

## Build

```bash
make noxary/378_2:vial
```

## Flash

```bash
make noxary/378_2:vial:flash
```

Then open the board in [Vial](https://get.vial.today/).

# Minimi40

This is the wired Minimi40 Ortho PCB. The hotswap and solderable versions use the same firmware.

This firmware can also be used on the GEON F1-40 Ortho.

Only the ortho version is included here. The staggered version exists in upstream QMK but has not been tested with Vial.

* Keyboard Maintainer: [Andrew Kannan](https://github.com/awkannan)  
* Hardware Availability: [CannonKeys](https://cannonkeys.com)

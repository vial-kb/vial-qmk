  <name>Task 1: Enable press-and-hold and swipe gestures in config.h</name>
  <files>keyboards/hidpress/bipedalambi/config.h</files>
  <action>
Add gesture enable overrides to config.h in the pointing device section (after the existing TPS43/split pointing defines, before the auto mouse section).

Add these defines:

```c
// TPS43 gesture enables (override driver defaults)
// Tap and two-finger tap are already enabled by default in the driver.
// Scroll is already enabled by default in the driver.
// Press-and-hold and swipe are disabled by default -- enable them here.
#define AZOTEQ_IQS5XX_PRESS_AND_HOLD_ENABLE true
#define AZOTEQ_IQS5XX_SWIPE_X_ENABLE true
```

These macros are checked via `#ifndef` guards in `drivers/sensors/azoteq_iqs5xx.c` (lines 29-46). Defining them in config.h overrides the defaults.

**Driver gesture-to-button mapping (already implemented in pointing_device_drivers.c):**
- `single_tap` -> POINTING_DEVICE_BUTTON1 (left click) -- default enabled
- `press_and_hold` -> POINTING_DEVICE_BUTTON1 (held left click / drag) -- default DISABLED, enabling here
- `two_finger_tap` -> POINTING_DEVICE_BUTTON2 (right click) -- default enabled
- `scroll` -> h/v scroll values -- default enabled
- `swipe_x_neg` -> POINTING_DEVICE_BUTTON4 (back) -- default DISABLED, enabling here
- `swipe_x_pos` -> POINTING_DEVICE_BUTTON5 (forward) -- default DISABLED, enabling here

Do NOT enable `AZOTEQ_IQS5XX_SWIPE_Y_ENABLE` -- vertical swipes map to BUTTON6/BUTTON3 which are not browser back/forward. Only horizontal swipes (X) are needed for TPAD-06.

Do NOT enable `AZOTEQ_IQS5XX_ZOOM_ENABLE` -- zoom is out of scope per REQUIREMENTS.md.

Build both halves to verify compilation:
```
make hidpress/bipedalambi:vial
make hidpress/bipedalambi:vial:clean && make hidpress/bipedalambi:vial SIDE=right
```

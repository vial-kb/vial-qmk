# Requirements: Bipedal Ambi -- Split Keyboard Firmware

**Defined:** 2026-02-22
**Core Value:** Both halves must communicate reliably over TRRS -- slave key presses must register on master

## v1.2 Requirements

Requirements for v1.2 TPS43 Trackpad milestone. Each maps to roadmap phases.

### Trackpad

- [x] **TPAD-01**: TPS43 trackpad moves the mouse cursor on the right half
- [x] **TPAD-02**: Single-finger tap registers as left click
- [x] **TPAD-03**: Two-finger tap registers as right click
- [x] **TPAD-04**: Two-finger scroll sends scroll events
- [x] **TPAD-05**: Press-and-hold emulates held left click (drag)
- [ ] **TPAD-06**: Swipe gestures register as mouse buttons 4/5 (back/forward) — DEFERRED (hardware unreliable on 43mm pad)
- [x] **TPAD-07**: TPS43 coexists with OLED on shared I2C1 bus (GP18/GP19)
- [x] **TPAD-08**: Auto mouse layer activates on trackpad movement

### Joystick

- [x] **JOY-01**: Custom keys mode works unchanged (directional keycodes from dynamic keymap)
- [x] **JOY-02**: Scroll mode sends mouse wheel keycodes (KC_MS_WH_*) directly from ADC reads
- [x] **JOY-03**: Mouse mode removed -- only custom keys and scroll modes remain
- [x] **JOY-04**: TMB_MODE cycles between custom keys and scroll (2 modes)
- [x] **JOY-05**: Mode selection persists in EEPROM across power cycles

### Build

- [x] **BLD-01**: Both halves compile cleanly with azoteq_iqs5xx driver
- [x] **BLD-02**: Split pointing enabled with POINTING_DEVICE_RIGHT

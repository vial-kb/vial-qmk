    **DIAG-01: Document as SKIPPED**

    DIAG-01 (PIO conflict -- separate WS2812 and serial onto different PIO peripherals) is skipped.
    Reason: Phase 9 audit (AUDIT-03) proved WS2812 driver is never compiled because RGBLIGHT is disabled. PIO0 is completely free. No conflict exists to test. See SERIAL-AUDIT.md H4.

    Include DIAG-01 skip documentation in the commit message.

    **Why this matters:** The comment "Required for serial communication" in halconf.h is incorrect. The vendor serial driver (serial_vendor.c) uses PIO directly via the Pico SDK. It never calls sioStart() or references any ChibiOS SIO API. Removing these config lines eliminates: (a) unnecessary ChibiOS SIO HAL compilation, (b) UART0/UART1 peripheral reset at boot (sio_lld_init), (c) unused SIODriver struct allocations.

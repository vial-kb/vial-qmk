## Phase Details

### Phase 12: Driver Switch and Build Foundation
**Goal**: Both halves compile cleanly with the pointing device driver switched from analog_joystick to azoteq_iqs5xx, with I2C bus sharing configured
**Depends on**: Phase 11 (v1.1 complete)
**Requirements**: BLD-01, BLD-02, TPAD-07
**Success Criteria** (what must be TRUE):
  1. `make hidpress/bipedalambi:vial` compiles without errors (left half)
  2. `make hidpress/bipedalambi:vial SIDE=right` compiles without errors (right half)
  3. POINTING_DEVICE_RIGHT and SPLIT_POINTING_ENABLE are defined in build config
  4. TPS43 and OLED both have I2C1 (GP18/GP19) configured without address conflicts
**Plans**: 1 plan

Plans:
- [ ] 12-01-PLAN.md -- Switch driver to azoteq_iqs5xx, configure I2C coexistence, verify build

### Phase 13: Trackpad Cursor and Auto Mouse
**Goal**: User can move the mouse cursor by touching the TPS43 trackpad on the right half, and an auto mouse layer activates during trackpad movement
**Depends on**: Phase 12
**Requirements**: TPAD-01, TPAD-08
**Success Criteria** (what must be TRUE):
  1. Touching the TPS43 trackpad on the right half moves the mouse cursor on screen
  2. Cursor movement is smooth and responsive (no jitter, no stuck axes)
  3. Auto mouse layer activates when the trackpad is touched and deactivates after movement stops
**Plans**: 1 plan

Plans:
- [ ] 13-01-PLAN.md -- Enable TPS43 cursor movement and auto mouse layer (config + keymap + flash verification)

### Phase 14: Trackpad Gestures
**Goal**: All TPS43 gesture types register as the correct mouse events -- taps, scrolls, drag, and navigation swipes
**Depends on**: Phase 13
**Requirements**: TPAD-02, TPAD-03, TPAD-04, TPAD-05, TPAD-06
**Success Criteria** (what must be TRUE):
  1. Single-finger tap on trackpad registers as left click
  2. Two-finger tap on trackpad registers as right click
  3. Two-finger vertical slide sends scroll up/down events
  4. Press-and-hold on trackpad enables drag (held left click)
  5. Swipe gestures register as mouse buttons 4/5 (browser back/forward)
**Plans**: 1 plan

Plans:
- [x] 14-01-PLAN.md -- Enable press-and-hold gesture, phantom right-click filter, swipe deferred (completed 2026-02-22)

### Phase 15: Joystick Refactor
**Goal**: Joystick operates in only two modes (custom keys and scroll), with scroll mode sending mouse wheel keycodes directly from ADC, and mode cycling updated
**Depends on**: Phase 12 (driver compiles), independent of Phases 13-14
**Requirements**: JOY-01, JOY-02, JOY-03, JOY-04, JOY-05
**Success Criteria** (what must be TRUE):
  1. Joystick custom keys mode works unchanged -- directional keycodes fire from dynamic keymap
  2. Joystick scroll mode sends KC_MS_WH_UP/DOWN/LEFT/RIGHT based on ADC deflection
  3. TMB_MODE keycode cycles between exactly 2 modes: custom keys and scroll
  4. Selected joystick mode persists in EEPROM across power cycles
  5. No mouse mode code remains -- joystick never moves the mouse cursor
**Plans**: 1 plan

Plans:
- [ ] 15-01-PLAN.md -- Remove mouse mode, add scroll wheel keycodes from ADC, update mode cycling and OLED

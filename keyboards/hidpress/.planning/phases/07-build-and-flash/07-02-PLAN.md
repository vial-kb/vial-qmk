## Flash and EEPROM Clear Procedure

Both UF2 firmware files are ready in the build directory:
- **Left:** `/Users/matthewthomas/dev/vial-qmk/.build/hidpress_bipedalambi_vial_left.uf2`
- **Right:** `/Users/matthewthomas/dev/vial-qmk/.build/hidpress_bipedalambi_vial_right.uf2`

### Step 1: Flash the Left Half

**Option A: make flash (recommended)**
1. Run from terminal: `cd /Users/matthewthomas/dev/vial-qmk && make hidpress/bipedalambi:vial_left:flash`
2. The terminal will say "Waiting for drive..."
3. Enter bootloader on the left half: **double-tap the reset button** (or hold BOOTSEL while plugging in USB)
4. The RPI-RP2 drive appears, `make flash` auto-deploys the UF2
5. The keyboard reboots automatically

**Option B: Manual copy**
1. Enter bootloader on the left half (double-tap reset or hold BOOTSEL while plugging in)
2. A drive named **RPI-RP2** appears in Finder
3. Copy the UF2 file: `cp /Users/matthewthomas/dev/vial-qmk/.build/hidpress_bipedalambi_vial_left.uf2 /Volumes/RPI-RP2/`
4. The drive auto-ejects and the keyboard reboots

### Step 2: Clear EEPROM on the Left Half

**CRITICAL: EEPROM must be cleared because the matrix dimensions changed (rows 4 to 8). Stale EEPROM will cause the exact layer offset bugs we are fixing.**

After the left half boots with new firmware:
1. Hold **MO(1)** (the key at the KC_MINS position in the bottom thumb row)
2. While holding MO(1), press the key at the **KC_DOWN position** (bottom-right key)
3. The keyboard reboots (brief USB disconnect/reconnect)
4. **Verify:** The left half should boot normally after the reboot

If EE_CLR does not work (key positions may differ from expectation), use Bootmagic instead:
1. Unplug the left half from USB
2. Hold **KC_ESC** (top-left key)
3. While holding KC_ESC, plug in the USB cable
4. EEPROM clears and keyboard enters bootloader mode
5. Unplug and replug to boot normally with cleared EEPROM

### Step 3: Flash the Right Half

Repeat Step 1 using the right half firmware:
- **make flash:** `cd /Users/matthewthomas/dev/vial-qmk && make hidpress/bipedalambi:vial_right:flash`
- **Manual copy:** `cp /Users/matthewthomas/dev/vial-qmk/.build/hidpress_bipedalambi_vial_right.uf2 /Volumes/RPI-RP2/`

### Step 4: Clear EEPROM on the Right Half

After the right half boots with new firmware:
1. Hold **MO(1)** (the bottom key)
2. While holding MO(1), press the key at the **KC_EQL position** (adjacent to MO(1))
3. The keyboard reboots (brief USB disconnect/reconnect)
4. **Verify:** The right half should boot normally after the reboot

If EE_CLR does not work, use Bootmagic:
1. Unplug the right half from USB
2. Hold **KC_BSPC** (top-right key)
3. While holding KC_BSPC, plug in the USB cable
4. EEPROM clears and keyboard enters bootloader mode
5. Unplug and replug to boot normally

### Step 5: Verify Both Halves Boot

1. Connect the left half via USB
2. Confirm it enumerates as a USB HID device (appears in System Information or `ioreg -p IOUSB`)
3. Connect the right half via the split cable
4. Both halves should respond to key presses

### Success Indicators

- Both halves boot without entering bootloader mode
- No unusual behavior (no stuck keys, no unresponsive keys)
- USB connection is stable (no repeated connect/disconnect sounds)

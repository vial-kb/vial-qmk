<objective>
Fix both vial.json matrix dimensions and remap right-half KLE layout positions.

Purpose: This is the core bug fix that resolves the EEPROM layer offset problem. The vial.json files currently declare rows=4 while config.h declares MATRIX_ROWS=8, causing Vial to calculate wrong EEPROM offsets for layers 1+. Additionally, the right-half KLE layout uses rows 0-3 instead of the correct rows 4-7.

Output: Two corrected vial.json files -- left with rows=8, right with rows=8 and all 25 key positions remapped from rows 0-3 to rows 4-7.
</objective>
